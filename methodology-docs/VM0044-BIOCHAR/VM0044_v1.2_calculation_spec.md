# VM0044 v1.2: biochar, calculation specification for the platform

**Implemented in:** `backend/app/calculation/modules/vm0044_v1_2.py`, module `VM0044-V1.2`. The methodology version must be **code `VM0044`, label `1.2`**.

**Tests:** `tests/test_vm0044_biochar.py`.

**Equations:** in `extract_vm0044.md`. All 16 equations were checked against the v1.1 PDF page images; v1.2 changed only additionality.

## Chain (one project = one production facility; per monitoring period)
1. **CC (Eqs. 2/6)** = M_used × F_Cp × PR_de.
   - **F_Cp:**
     - Lab value (`V44_FCP`). It is mandatory for high-technology plants.
     - Otherwise the Table 4 value for the feedstock and process (`V44_FEEDSTOCK`, `V44_PROCESS`).
   - **PR_de (Table 3):**
     - above 600 °C: 0.89;
     - above 450 °C up to 600 °C: 0.80;
     - 350–450 °C: 0.65;
     - not measured or below 350 °C: 0.56.
2. **PE_PS (Eqs. 3/7)** = (pre-treatment + P_EP + auxiliary energy) × M_used / M_produced.
   - High technology: P_EP = 0.
   - Low technology: P_EP = F_e (default 0.049) × 28 × M_used (Eq. 9).
3. **PE_AS (Eqs. 11/12)** is the processing emissions. **LE (Eq. 13)** is the transport emissions, counting only legs with a round trip of 200 km or more.
4. **ER (Eqs. 1, 15)** = CC × 44/12 − PE_PS − PE_AS − LE.
   - There is no uncertainty deduction and no buffer (VM0044 has neither; permanence is handled by PR_de).
   - VCUs are whole tonnes, rounded down.

## Questions resolved
| # | Question | Answer used |
|---|---|---|
| B1 | Eq. 1 would subtract production emissions once per biochar type | Subtracted once per facility |
| B2 | Table 3 overlaps at 450 °C and does not cover temperatures below 350 °C | 450 °C → 0.65 (the lower value); below 350 °C → 0.56 |
| B3 | Is H:C_org used for permanence? | No. It is only the soil eligibility gate (≤ 0.7 per batch); the platform refuses ineligible soil biochar |
| B4 | Where do the TOOL05 / TOOL03 / TOOL12 results come from? | Calculated outside the platform and recorded in t CO2e (`V44_PE_PRETREAT`, `V44_PE_AUX`, `V44_PE_PROCESSING`, `V44_LE_TRANSPORT`) |
| B5 | GWP | CH4 28 (AR5; VCS Standard v5.0) |

## Data (Monitoring data, project level, per batch, application or period)
- **Quantities (t, dry):** `V44_PRODUCED`, `V44_USED_SOIL`, `V44_USED_NONSOIL`.
- **Lab and process:**
  - `V44_FCP` (fraction);
  - `V44_HC_RATIO` (ratio, each batch);
  - `V44_TEMP` (°C).
- **Classification:**
  - `V44_TECH` (HIGH / LOW);
  - `V44_FEEDSTOCK` (WOOD, HERBACEOUS, RICE, NUTSHELL, MANURE, BIOSOLIDS);
  - `V44_PROCESS` (PYROLYSIS / GASIFICATION);
  - `V44_FE` (kiln-specific t CH4/t, optional).
