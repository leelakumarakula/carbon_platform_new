## 2. Calculation chain: platform steps → VM0042 equations

The platform's calculation engine runs 8 fixed steps. Mapping for the Phase 1 scope:

| Platform step | VM0042 | What is computed |
|---|---|---|
| **BASELINE** | Eq. 3 (+ ESM), Eq. 46; Eqs. 6–9, 11–14, 16–32 with *bsl* data | SOC stock per sample → ESM → stratum mean → baseline SOC change at **control sites**; baseline emissions per source |
| **PROJECT** | Eq. 3 (+ ESM), Eq. 47; the same emission equations with *wp* data (8.3) | Project SOC change; project emissions per source |
| **EMISSIONS** | Eqs. 52–59 | Emission **reductions** per source = Σ (baseline − project) × area |
| **REMOVALS** | Eqs. 44, 45, 40 | Carbon stock change (SOC, ×44/12), with the uncertainty sign switch I(ΔCO2_soil) |
| **LEAKAGE** | Eqs. 33–36 (+ VMD0054), 39, 42 | Leakage, allocated pro rata to reductions and removals |
| **UNCERTAINTY** | Eqs. 70, 71, 74 | Variance of the mean SOC change per stratum → project → UNC % (t₀.₆₆₇ ≈ 0.4307) |
| **ADJUSTMENT** | Eqs. 75, 76 | Non-permanence buffer (NPR %) on the carbon-stock part |
| **NET** | Eqs. 37, 38, 41, 43, 77–79 | ER_NET, CR_NET → VCU_ER, VCU_CR → **VCU_t** |

### Core formulas (as printed)

- **Eq. 3, SOC mass per sample and depth layer:** `M_SOC (kg/ha) = ( M_sample(g) / (π·(D/2)²·N) × 10 000 ) × OC (g/kg)`. D = probe inside diameter (mm), N = number of cores.
- **ESM adjustment:** the cumulative SOC mass is interpolated to reference soil masses by **cubic spline** (Wendt & Hauser 2013 spreadsheet, or the von Haden 2020 R script). VM0042 prints no equation for it; it is defined by those sources.
- **Eqs. 46/47, SOC change:** `ΔCO2_soil = Σ_i ( (SOC̄_i,t − SOC̄_i,t−x) × 1/x ) × A_i`, converted with 44/12.
- **Eq. 74, uncertainty:** `UNC = ( √s² / Δ̄ × 100 ) × t₀.₆₆₇`
- **Eq. 77–79, credits:** `VCU_t = (ER_NET,t − Bu_ER,t) + (CR_NET,t − Bu_CR,t)`

### Sampling rules (VM0042 §8.2.1)

- Report SOC to at least **30 cm** on an **ESM basis**. Sample deeper, in **at least 2 depth increments** (recommended 0–30 and 30–50 cm).
- **Stratified random** sampling. At least **3–5 composite samples per stratum** (Q4).
- **At least 3 control sites**, at least **1 per stratum**, within **250 km**, meeting the Table 7 similarity criteria: slope class, texture class, FAO soil group, SOC % and more.
- Remeasure at **each verification**, same season, same lab and same methods. Particles over **2 mm** excluded.
- SOC by **dry combustion** preferred. Walkley-Black and loss-on-ignition are "not recommended".
- Record **planned and actual GPS** for every point.

**Evidence rule (Box 1):** baseline practice data must come from the highest available tier:
1. records or remote sensing;
2. management plans;

## 5. Platform changes needed for Phase 1

1. **Control sites:** new entity (location, strata links, similarity criteria, baseline schedule), sampled with the same flow.
2. **Multiple depth increments per sample.** Probe diameter and core count on the field record.
3. **Lab rules:** `soil_mass` (g) per increment, `organic_carbon` (g/kg), method recorded.
4. **Farm activity records** with quantities (fuel, lime, fertiliser N, livestock, burning) for baseline (t = −1…−3) and project years, with an evidence tier.
5. **ESM engine:** cubic-spline ESM (reproducing the Wendt & Hauser spreadsheet).
6. **IPCC 2019 emission-factor table:** reference data, versioned, with source citations.
7. **NPR %** input: the non-permanence risk rating per verification (from the AFOLU risk tool).
8. **Calculation tab:** module dropdown and read-only equation view. **Production-readiness approval.**

| # | Question | Pages |
|---|---|---|
| Q1 | **RESOLVED (conditional; VM0042 Table 5 & §5, VCS Standard v5.0 §3.14.6):** the scope is valid. VM0042 allows different approaches per source (same approach in baseline and project per unit). Approach 1 is optional (only where a valid model exists). Woody biomass is **mandatory only where the project may significantly reduce it** (§8.3). Leakage 8.4.4 / TOOL16 applies **only where residues used for energy are diverted**. Sources below **5 %** may be excluded as de minimis. **Condition:** the project confirms no significant woody-biomass decrease and no diversion of residues used for energy; otherwise those modules are added before credits are claimed. | — |
| Q2 | ~~Eq. 74 yields UNC in %, Eqs. 37/44/45 use a fraction~~ **RESOLVED:** dimensional consistency requires UNC/100 in Eqs. 37/44/45; VCS Methodology Requirements v5.0 §2.4 expresses uncertainty as a percentage of the estimate. Implement `UNC_fraction = UNC% / 100`. | 59, 61–62, 88 |
| Q3 | **RESOLVED (VCS Standard v5.0 §3.2.21–3.2.23; Registration & Issuance Process v4.4 §5.3):** a negative stock change is not a negative buffer deposit — it is a **loss event / reversal**. The buffer deposit is never below zero (`Bu = max(0, …)`). When the net carbon-stock benefit for the period is negative, no VCUs are issued from removals, the loss is reported (Loss Event Report), and Verra **cancels buffer credits** to cover it (avoidable reversals also block further issuance until remedied). The platform must flag this as a REVERSAL outcome rather than compute negative credits. | 90–91 |
| Q4 | ~~Minimum composite samples per stratum: 3 or 5?~~ **RESOLVED (2026-10-05):** the project sets the number of samples per stratum in its sampling design. VM0042's minimum of **3** is configured as the methodology SAMPLING rule `min_samples_per_stratum = 3`, which the platform already enforces when a design is created. The calculation uses every collected, lab-approved sample. | 34 |
| Q5 | **RESOLVED (Verra SSA Handbook draft v1.0, p.21 and Appendix 7.1):** one-sided Student-t critical value at **66.67 %** (the handbook's t(1)=0.667 for "a one-sided 66.67 confidence interval"); 0.4307 is its large-sample limit. Degrees of freedom: **Welch–Satterthwaite** approximation when variances from strata / time points are combined (handbook eq. 23), which reduces to n − 1 for a single simple sample. The platform computes the t-value from the Student distribution with these degrees of freedom. | 88 |
| Q6 | **RESOLVED (VM0042 Eqs. 44/45 indicator logic; VCS Methodology Requirements v5.0 §2.4 — uncertainty matters where it can over-estimate):** compute UNC with the **absolute** mean, `UNC = t × √s² / |Δ̄| × 100`; the sign indicator I(ΔCO2_soil) in Eqs. 44/45 then enlarges a loss (conservative). If Δ̄ = 0 the term UNC multiplies is 0, so no credit arises; UNC is **capped at 100 %** so (1 − UNC) never flips the sign of a gain. | 88 |
| Q7 | **RESOLVED (standard stratified-random notation, Cochran; VM0042 §8.2.1.2 requires stratified random sampling):** A = total area of the quantification unit (Σ A_h), A_h = area of stratum h, n_h = composite samples in stratum h, H = number of strata, L = number of quantification units. Eq. 70 is the textbook variance of a stratified mean: (1/A²) Σ A_h² s_h² / n_h. | 82–83 |
| Q8 | **RESOLVED (Verra SSA Handbook draft v1.0 §2.4 & §2.8):** the baseline control sites use **the same estimator** as the project strata (Eq. 71). With **independent sampling** (new random points at each campaign — the QA2 default), the variance of a change is the **sum of the two snapshot variances** (t0 and t); with **paired sampling** it is the variance of the per-unit changes. | 83 |
| Q9 | **RESOLVED (IPCC 2019 Refinement Vol. 4 Ch. 11, Eq. 11.5 — the source VM0042 reproduces):** F (manure N deposited) is in **kg N yr⁻¹** (Pop × Nex[kg N/head/yr] × MS). The "t N" label in VM0042 is the error; Eq. 27's ÷1000 is correct, and **Eqs. 30–31 must apply the same ÷1000** (kg → t) before multiplying by 44/28 and GWP. | 50–51 |
| Q10 | **RESOLVED (IPCC 2019 Refinement Eq. 11.5 and Vol. 4 Ch. 10 structure):** emissions are **summed over every livestock type l, productivity system P and manure-management system S** present in the quantification unit, each with its own population, Nex, MS and emission factor. | 44–51 |
| Q11 | **RESOLVED (IPCC 2019 Refinement Vol. 4 Ch. 11, Tier 1 note):** FracLEACH-(H) = **0.24** in wet climates, or in dry climates where irrigation **other than drip** is used; **0** in dry climates otherwise — so dry + drip = **0**. | 51, 126 |
| Q12 | **RESOLVED (Verra SSA Handbook draft v1.0, §6):** (a) ESM uses **mineral** soil mass = fine-earth dry mass **minus SOM** (SOC × 1/0.58), **corrected for coarse fragments**; (b) interpolation: **linear** when only 2 depth increments (mandatory), **cubic spline** (Wendt & Hauser / von Haden) or linear when ≥ 3 increments — the same function for the whole crediting period; (c) reference soil mass for **independent sampling under QA2 = the average mineral soil mass to 30 cm at the linked baseline control site(s) at t0**; for paired sampling, each location's t0 mass to 30 cm. | 39–41 |
| Q13 | **RESOLVED (defaults; IPCC 2019 Refinement Vol. 4 Ch. 11, Tables 11.1 & 11.3):** climate per quantification unit — tropical **wet if annual precipitation > 1000 mm**, else dry. EF1: wet synthetic **0.016**, wet other N **0.006**, dry all N **0.005** (aggregated 0.010); flooded rice EF1FR 0.004 (continuous 0.003, drainage 0.005); EF4: wet **0.014**, dry **0.005**; EF5 **0.011**; FracGASF: urea **0.15**, ammonium **0.08**, nitrate **0.01**, ammonium-nitrate **0.05** (aggregated 0.11); FracGASM **0.21**; FracLEACH see Q11.
