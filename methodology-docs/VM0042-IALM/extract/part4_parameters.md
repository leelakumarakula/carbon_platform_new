- **SOC-A2** = SOC stock change, Quantification Approach 2 (measure & remeasure)
- **A3-FF** fossil fuel CO2; **A3-LIME** liming CO2; **A3-N2O** fertilizer / N-fixing N2O; **A3-MAN** manure CH4/N2O; **A3-ENT** enteric CH4; **A3-BURN** biomass burning CH4/N2O (all Approach 3 default-factor emissions)

## 5. Ambiguities and issues (with page references)

- **A1 (p.100, also p.37–38):** The symbol for the t-distribution value renders as "t<sub>x,u</sub>" in both the PDF and the text layer, which looks like a glyph substitution. The description refers to "power level (1 − b) and a significance level" and the eq (1)–(2) "Where" list (p.38) describes a two-sided critical value at significance level (α) and a one-sided quantile for the type II error (β). The intended symbol is presumably t<sub>α,β</sub>, but the exact printed symbol is [UNREADABLE].
- **A2 (p.98 vs p.115):** "S" is used for two different parameters: the standard deviation of the SOC difference (unit given as "Dimensionless", although it is a standard deviation of SOC stocks, which have unit t CO2e/ha) and the manure management system. Implementations need distinct identifiers.
- **A3 (p.94, p.123–124):** W<sub>bsl,l,i,t,P</sub> (a baseline parameter) has Purpose "Calculation of project emissions". NC<sub>OF</sub> has Purpose "Calculation of baseline emissions" only, although it is also needed for the project scenario via eq (20) with M<sub>wp,OF</sub>. Both appear to be drafting slips.
- **A4:** There is no 9.2 (project-scenario) table for the liming masses M<sub>Limestone/Dolomite,wp,i,t</sub>, the livestock N-deposition fraction MS<sub>wp,l,i,t</sub>, or the 9.1 baseline items in general. The project equivalents are implied by the "[WP] substitute bsl by wp" convention used elsewhere, but have no explicit tables. Similarly, no parameter table exists for the Approach 2 uncertainty terms in eqs (70)–(73), for the Approach 1 model-error terms in (60)–(61), (64)–(69), or for LE<sub>OA,t</sub>. Only A is tabled for these.
- **A5 (p.139–140, also p.69–72):** The gas/pool symbol in the tables "Gas or pool" and "Areal mean emission reductions in gas or pool … (in stratum h)" renders as a bullet glyph in the PDF and as an unknown character in the text. Marked [UNREADABLE].
- **A6 (p.141, cf. p.91 eq 76):** BU<sub>CR,t</sub> is described as "Number of buffer credits to be deducted from **reductions** in year t", which is identical to BU<sub>ER,t</sub>. Equation (76) on p.91 defines it as buffer credits deducted from **removals**. Both buffer tables also give Purpose "Calculation of project emissions".
- **A7 (p.104, p.39 §8.2.1.5–8.2.1.6):** BD<sub>corr</sub> and d are "Only required when following Quantification Approach 1". Approach 2 uses the soil-mass/ESM route (eq 3: M<sub>n,dl,sample</sub>, D, N), so no bulk-density parameter table exists for Approach 2. However, the SOC<sub>bsl,i,t</sub>/SOC<sub>wp,i,t</sub> tables still say "See Section 8.2.1 for requirements for SOC content and bulk density measurements". The data platform may still need bulk density sampling per 8.2.1.5 (outside the tables).

The f(SOC<sub>bsl</sub>) table (p.105) describes Val A<sub>bsl,i,t</sub>/Val B<sub>bsl,i,t</sub> as values "in the **project** scenario". Notation also alternates between "Val" (p.105, p.120) and "Var" (p.110, p.135).

- **A10 (p.100–104):** Frequency wording differs between tables. M<sub>n,dl,SOC</sub>, M<sub>n,dl,sample</sub>, D, N, OC<sub>n,dl</sub> and t<sub>α,β</sub> include "or, when following quantification approach 2, prior to each verification event…".
